# The reader exercise

The apparatus now passes every check it owns, and none of those
checks can answer the question the site exists for: does it answer a
question a person actually arrives with? This directory holds the
method for finding out, made active on 2026-09-11 by the founder's
direction after the September check-in: one owner network worked all
the way through, a report iterated alongside the tools.

One boundary, stated before any name is chosen. This directory holds
method only. The worked report names a real network and stays out of
this repository, as founder-facing work product, because a public
document analyzing one named network, one directory over from a site
whose charter refuses single-name campaigns, would be that campaign
in a different costume. The method is public because method travels;
the analysis is not, because the charter's line does not move for
our own convenience.
